## ขั้น 1 — ชิ้นลองสวม (ส่งก่อน) · `SF_ClipsalH_fit_3sizes.stl`
- 3 ชิ้นในไฟล์เดียว เบอร์ **1 / 2 / 3** = ช่องใน **115.6×73.6 / 116.0×74.0 / 116.6×74.6** (`FIT_GAPS = [0.3, 0.5, 0.8]`)
- ผนัง 0.8 สูง 5.3 มม. + แถบกากบาทแนวกลาง (กว้าง 3, หนา 0.6) มีรอยบากที่ขอบทุก 5 มม. (รอยลึกทุก 10 มม.) รูกลมตรงกึ่งกลาง
- เลขเบอร์ตัดทะลุป้ายมุมซ้ายบน (อ่านถูกด้านเมื่อมองจากหน้า)
- รวม 3 ชิ้น ≈ **7.9 g** (PETG) · พิมพ์คว่ำ แถบไม้บรรทัดติดฐาน ไม่ต้องซัพพอร์ต · ใช้ฐาน 118×234 มม.
- สีเข้ม (เช่น กรมท่าเข้ม) ตัดกับหน้ากากขาว ถ่ายรูปอ่านรอยบากง่าย

## ขั้น 2 — ตัวจริงร่าง V1
- `SF_ClipsalH_frame_1lever.stl` / `SF_ClipsalH_frame_2lever.stl` + `SF_ClipsalH_lever.stl` (รุ่น 2 คันโยกพิมพ์คันโยก 2 อัน)
- กรอบนอก 119.8 × 77.8 × หนา 23 มม. · ผนัง 1.91 · หน้า 2.0 · มุม R3.5 ขอบหน้ามน R1.2 · ช่องคันโยก 9.5×24 (เท่ารุ่นเดิม)
- คันโยกหัวกลม Ø24 ยื่นจากผิวกรอบ 23 (เท่ารุ่นเดิม) · ด้านข้างหัวตัดเรียบ 1 ด้านเพื่อพิมพ์นอนไม่ต้องซัพพอร์ต
- กลไก: กระดานหก แขนกด 2 ข้าง (±9.5 มม.) กดครึ่งบน/ล่างของปุ่มกระดก · **ดันหัวขึ้น = กดครึ่งบน** · ดันลง = กดครึ่งล่าง
- แกนหมุน = เส้น filament 1.75 ตัดยาว ≈ 14.4 มม. เสียบผ่านหูยึด–คันโยก–หูยึด (รูหูยึด 1.85 คับ / รูคันโยก 2.05 หมุนลื่น)
- ใส่คันโยกจากด้านหน้า ลอดช่องเข้าไป (แขนกว้างรวม ~22 < ช่อง 24) แล้วเสียบแกนจากด้านหลังกรอบ
- ขาแปะเทป 2 หน้า 4 มุม 7×7 มม. ลงมาแตะผิวหน้ากาก (Z = 11)
- คู่สีเดิม R3D PETG Matte (ภาพใช้ ขาว × เหลือง)

## ตัวแปรที่ต้องแก้หลังได้รูปชิ้นลองสวม
| ตัวแปร | ค่าตอนนี้ | แก้เมื่อ |
|---|---|---|
| `FIT_GAP` | 0.5 (= เบอร์ 2) | เบอร์ที่สวมแน่นพอดี: 1→0.3 · 2→0.5 · 3→0.8 |
| `LEVERS_1` | `[[0,0]]` | ปุ่ม 1 ช่องไม่อยู่กลาง |
| `LEVERS_2` | `[[-14.5,0],[14.5,0]]` | อ่านกึ่งกลางปุ่มจากรอยบากแถบแนวนอน (ค่าประมาณ) |
| `ROCKER_HALF` | 9.5 | ระยะจากกลางปุ่มถึงจุดกด (ปุ่มสูง ~40) |
| `ROCKER_Z` | 13.5 | ระดับปลายแขนกดจากผนัง (หน้ากาก 11 + ปุ่มยื่น) |
| `FRAME_D` | 23 | อยากให้บางลง (ต้องให้ดุมลอยเหนือปุ่มเสมอ) |
| `PLATE_T` | 11 | ความหนาหน้ากากจริง |

แก้ได้ทั้งในไฟล์ `.scad` หรือใส่ใน `REAL_OVERRIDES` ของ `export_all.py`
